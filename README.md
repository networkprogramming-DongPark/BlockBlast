# 블록 매치

2인 대전 블록 퍼즐 게임입니다. 설계 내용은 [Common/docs/DESIGN.md](Common/docs/DESIGN.md)를 참고하세요.

| 폴더 | 역할 |
| --- | --- |
| `Common` | 공용 모델, 설계 문서 |
| `Client` | Java Swing 게임 클라이언트 |
| `Server` | 게임 서버 |

## 개발 환경 준비

```bash
git clone https://github.com/networkprogramming-DongPark/BlockBlast.git
```

IntelliJ IDEA에서 `BlockBlast` 폴더를 열면 `Common`, `Client`, `Server` 모듈이 함께 불러와집니다. JDK를 찾지 못한다는 안내가 나오면 Project Structure에서 JDK 17 이상을 지정합니다.

## 실행

IntelliJ에서는 `blockmatch.server.ServerMain`을 먼저 실행한 뒤 `blockmatch.client.ClientMain`을 두 번 실행합니다. 두 번째 실행을 위해 Run Configuration에서 Allow multiple instances를 켭니다. 클라이언트를 실행하면 메인 화면이 뜨고, 닉네임을 입력한 뒤 "게임 시작"을 누르면 서버에 접속해 게임 화면으로 넘어갑니다.

명령줄에서는 저장소 최상위 폴더에서 다음과 같이 실행합니다. (Git Bash 기준, JDK 17 이상)

```bash
javac -encoding UTF-8 -d out $(find Common/src Client/src Server/src -name '*.java')
java -cp out blockmatch.server.ServerMain
```

서버의 실행 인자는 `[제한 시간(초)]`이고 생략하면 5분(300초)입니다. 시연할 때 `java -cp out blockmatch.server.ServerMain 60`처럼 짧게 줄 수 있습니다.

터미널을 두 개 더 열어 클라이언트를 각각 실행합니다. 실행 인자는 `[닉네임] [서버 주소]`이고 둘 다 생략할 수 있습니다. 닉네임을 주면 메인 화면의 입력 칸에 미리 채워지고, 서버 주소를 생략하면 `localhost`에 접속합니다.

```bash
java -cp out blockmatch.client.ClientMain 동오
```

```bash
java -cp out blockmatch.client.ClientMain 성훈
```

접속 상태와 채팅은 게임 창의 채팅 영역에, 주고받은 메시지는 서버 콘솔에 표시됩니다. 두 명이 모두 입장해 게임이 시작된 뒤에 채팅을 보낼 수 있고, 보낸 채팅은 두 플레이어에게 전달됩니다. 채팅 영역은 닫힌 채로 시작하며, 두 보드 사이 아래쪽의 말풍선 버튼으로 열고 닫습니다. 창 크기는 바뀌지 않고, 채팅 영역을 열면 그 폭만큼 게임 화면이 줄어들어 가려지는 곳 없이 모두 보입니다. 닫아 둔 동안 상대가 보낸 채팅 수는 버튼에 표시됩니다.

말풍선 버튼 왼쪽의 얼굴 버튼을 누르면 이모티콘(웃음, 화남, 슬픔, 지루함)과 빠른 문구("블록을 빨리 놔주세요", "잘하시네요!", "잠깐만 기다려 주세요")를 고를 수 있고, 누르는 즉시 일반 채팅처럼 두 플레이어에게 전달됩니다. 이모티콘은 보낸 사람의 점수 옆에도 잠시 나타납니다. 채팅 영역이 닫혀 있어도 보낼 수 있습니다. 오른쪽의 나가기 버튼은 메인 화면으로 돌아가며, 게임 중에는 한 번 더 묻습니다.

상대가 나가면 "접속을 종료했습니다", 같은 이름으로 다시 들어오면 "재접속했습니다"가 채팅 영역에 표시됩니다. 서버는 꺼질 때까지 접속을 계속 받으며, 두 자리가 다 찬 상태에서 들어오려 하면 "방이 가득 찼습니다", 이미 쓰는 닉네임이면 거부됩니다. 둘 다 나가면 새 게임을 시작할 수 있습니다.

닉네임은 메인 화면에서 1~10자로 입력하며 `|`는 쓸 수 없습니다. 상대와 같은 닉네임이거나 방이 가득 차 입장이 거부되면, 서버에 접속할 수 없으면, 또는 게임 중 연결이 끊기면 메인 화면으로 돌아와 그 이유를 보여 줍니다. 게임이 끝나면 새 창이 아니라 게임 화면 위에 결과가 크게 나타납니다. 이기면 금빛 WIN 글자와 함께 빛줄기, 반짝이는 별, 색종이가 나오고, 지면 화면이 어두워지며 비가 내리는 가운데 회색 LOSE 글자가 힘없이 떨어집니다. 비기면 DRAW가 나옵니다. 그 아래의 "다시 게임하기"와 "메인으로 돌아가기" 버튼으로 다음을 고릅니다. 두 사람이 모두 다시 게임하기를 누르면 같은 상대와 새 게임이 바로 시작됩니다. 한 명이 먼저 누르면 그 사람에게는 "상대방을 기다리는 중...", 상대에게는 "한판 더해요!"가 보입니다. 상대가 메인으로 돌아가거나 창을 닫으면 "상대방이 나갔습니다."가 뜨고 메인으로 돌아가기만 할 수 있습니다. 메인 화면으로 돌아오면 지난 게임 결과가 남고, 다시 "게임 시작"을 누르면 새 게임에 들어갑니다. 게임 창을 닫아도 메인 화면으로 돌아갑니다.

두 명이 입장하면 서버가 블록 3개씩을 나눠 주고 게임이 시작됩니다. 내 보드 아래의 블록을 마우스로 끌어 내 보드에 놓으면, 서버가 놓을 수 있는지 판정한 뒤 두 플레이어에게 바뀐 상태를 보냅니다. 그래서 내가 놓은 블록과 점수는 상대 창의 "상대 보드"에도 바로 보입니다. 가로나 세로 줄을 채우면 그 줄이 지워지고 점수가 오릅니다. 지워질 때는 블록이 반짝인 뒤 조각으로 부서지며, 얻은 점수가 보드 위에 떠오릅니다. 여러 줄을 한 번에 지우면 DOUBLE, TRIPLE 등이, 연속으로 지우면 COMBO가 표시됩니다. 효과음은 코드로 만들어 별도 음원 파일이 없습니다. 서버에 연결되지 않은 상태에서는 블록을 놓을 수 없습니다.

새로 받는 블록 3개는 각각 그 순간의 보드에 놓을 수 있는 모양으로만 나옵니다. 다만 앞의 블록을 잘못 놓으면 나머지 블록을 놓을 곳이 없어질 수 있습니다. 두 보드 사이에 남은 시간이 표시되고, 5분이 끝나면 점수가 높은 사람이 이깁니다(같으면 무승부). 시간이 끝나기 전에 남은 블록을 하나도 놓을 수 없게 된 사람은 그 즉시 집니다. 결과는 게임 화면 위에 WIN, LOSE, DRAW로, 자세한 내용은 결과 화면과 채팅 영역에 표시됩니다.

## Wireshark로 통신 확인

1. Wireshark에서 `Adapter for loopback traffic capture`를 선택합니다. 서버와 클라이언트를 다른 PC에서 실행할 때는 실제 네트워크 어댑터를 선택합니다.
2. 디스플레이 필터에 `tcp.port == 30000`을 입력합니다.
3. 서버와 클라이언트 두 개를 실행합니다.
4. 패킷을 우클릭해 Follow > TCP Stream을 선택하고, 인코딩을 UTF-8로 지정하면 메시지를 읽을 수 있습니다.
