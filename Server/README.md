# 블록 매치 - Server

게임 서버입니다. `Common` 모듈이 필요합니다.

준비와 실행 방법은 [최상위 README](../README.md), 설계는 [DESIGN.md](../Common/docs/DESIGN.md)를 참고하세요.

현재는 플레이어 두 명의 접속을 받아 게임을 시작하고, 게임 상태의 원본을 가진 채 블록 배치 요청을 판정해 두 플레이어에게 상태를 보내는 단계까지 구현되어 있습니다. 채팅 중계와 접속 종료·재접속 처리, 놓을 수 있는 블록 나눠 주기, 제한 시간(기본 5분)과 게임 종료 판정, 두 플레이어가 모두 원할 때 다시 하기도 합니다.
